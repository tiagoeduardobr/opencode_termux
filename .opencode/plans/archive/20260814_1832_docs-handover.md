### Comportamento atual do stop script (140 linhas, lido e confirmado)
1. Carrega `.env` via `$SCRIPT_DIR` (raiz do repo) + defaults (`OPENCODE_PORT` default 4096, `OPENCODE_HOSTNAME` default 127.0.0.1)
2. Helpers `is_zombie()` (case `Z*` via `ps -o stat=`) e `kill_graceful()` (SIGTERM → 3×1s → SIGKILL, com break se morto ou zumbi)
3. Tratamento zombie-aware do PID do proot: PID morto → WARN; zumbi → WARN (reaped pelo init); válido → graceful; **sem `exit 0` precoce** no caminho "sem PID_FILE"
4. **Limpeza de órfãos que roda SEMPRE** (mesmo sem PID_FILE): Fase A SIGTERM → espera 3×1s (zumbi-aware, dedup com `sort -n | uniq`) → Fase B SIGKILL; alvos = `run-cloudflare-tunnel.sh` (variável `SCRIPT_PATTERN`), processo na porta `$OPENCODE_PORT` (via `port_pids()`: lsof primário → fuser fallback), `cloudflared tunnel --url http://127.0.0.1:${PORT}` (padrão com porta) — **NUNCA** `pkill -f "opencode web"` genérico
5. Verificação final: zumbis → `[INFO] ... sera reaped pelo init.`; vivos → `[WARN] Processo remanescente:` + `ps`; flag `remaining_alive`; WARN único quando lsof/fuser indisponíveis (`TOOLS_WARNED`)
6. Cleanup: `rm -f "$PID_FILE" "$NOTIFY_FILE" "$LOG_FILE"`, `stty sane 2>/dev/null || true`, `termux-wake-unlock 2>/dev/null || true`, `exit 0` final
