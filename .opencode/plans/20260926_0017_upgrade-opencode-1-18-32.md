> Sequenciais do OpenCode") e nos planos anteriores

## Objetivo

Atualizar o OpenCode (CLI global + plugin npm) de 1.18.30 para 1.18.32 em um
único salto, seguindo o pipeline consolidado do projeto:
branch → CLI no proot → plugin bump + lock → docs → validação → code review →
commit único → merge fast-forward.

Mudanças relevantes trazidas pelas 2 versões:

- **1.18.31** (14/09/2026): correções ACP de session model/effort/mode/reasoning;
  auth de remote config no TUI; adaptive thinking no GitHub Copilot.
- **1.18.32** (21/09/2026): Bedrock image attachments para Claude/Nova/Llama 4;
  reporting de uso em streaming da Together AI.

Impacto esperado no repositório: **nenhum** mudança de config, schema de
frontmatter de agentes ou contrato de skills (ambas as versões são aditivas /
bugfix). As mudanças no repo são exclusivamente de versão (package files) e
documentação.
