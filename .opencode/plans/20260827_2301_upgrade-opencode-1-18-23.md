# Plano: Upgrade OpenCode 1.18.21 → 1.18.23 (direto)

> **Base**: padrão de upgrade documentado em `AI_HANDOVER.md` (seção "Upgrades
> Sequenciais do OpenCode", 9 upgrades anteriores) e plano anterior
> `.opencode/plans/archive/20260823_2232_upgrade-opencode-1-18-21.md`.

## Objetivo

Atualizar o OpenCode (CLI global + plugin npm) de 1.18.21 para 1.18.23 em um
único salto (pulando 1.18.22), seguindo o pipeline consolidado do projeto:
branch → CLI no proot → plugin bump + lock → docs → code review → commit único
→ merge fast-forward.

Mudanças relevantes trazidas pelas 2 versões:
- **1.18.22**: removido messaging/pricing desatualizado do OpenCode Go; fix
  device login links com URLs de verificação relativas/base path; fix
  textVerbosity enviado a providers OpenAI-compatible que não suportam;
  provider Amazon Bedrock atualizado (compatibilidade); Desktop: headers de
  providers visíveis ao rolar model picker.
- **1.18.23**: fix Cloudflare AI Gateway routing para providers de terceiros
  (non-Workers via REST API); fix modelos Anthropic via Cloudflare AI Gateway
  (IDs com ponto → slug com traço); fix parent session IDs em headers para
  providers session-aware; TUI: fix GitHub auth para immutable OIDC subject
  tokens. — Nenhuma mudança afeta o workflow multi-agente local deste repo.

## Escopo

- **Dentro**: CLI global no proot; `.config/opencode/package.json` +
  `package-lock.json`; `AGENTS.md`; `docs/MULTI_AGENT_ORCHESTRATION.md`;
  `docs/SESSION_CONTEXT_20260618.md`; verificação de coerência.
- **Fora**: mudanças em agentes `.md`, skills, scripts (`bin/`, `scripts/`,
  `shell/`), `opencode.json`, `AI_HANDOVER.md` (atualização fica para sessão
  própria, como nos upgrades anteriores), PRs (projeto usa merge direto
  fast-forward).

## Assumptions

1. Branch base: `main` no HEAD atual (`d04a640`, upgrade 1.18.21, já pushado).
2. Changelogs 1.18.22/1.18.23 fornecidos pelo usuário são precisos (não há
   breaking change de config; 1.18.16+ ignora campos desconhecidos).
3. Nenhum campo novo obrigatório em `opencode.json` ou frontmatter de agentes.
4. `npm install` do plugin roda no mesmo ambiente do CLI (proot), onde node
   v26.2.0 / npm 11.17.0 estão disponíveis.
5. Data das entradas documentais: 27/08/2026.
6. Um único commit ao final (decisão do usuário), após code review obrigatório.
7. **5 arquivos modificados no repo** (correção do plano anterior, que dizia
   "4" mas listava 5: package.json, package-lock.json, AGENTS.md,
   MULTI_AGENT_ORCHESTRATION.md, SESSION_CONTEXT_20260618.md).

## Riscos

| Risco | Probabilidade | Impacto | Mitigação |
|-------|--------------|---------|-----------|
| `npm install -g` falha no proot (rede/registry/arm64) deixando CLI quebrado | Baixa | Alto | Task 1 isolada com verificação imediata (`opencode --version`); rollback simples: `npm install -g opencode-linux-arm64@1.18.21 --force` |
| Breaking change silenciosa em config/agentes/skills não listada nos changelogs | Baixa | Médio | Smoke test pós-upgrade (Checkpoint 1); changelogs indicam apenas fixes/features aditivas; 1.18.16+ ignora campos desconhecidos no config parsing; restart do opencode obrigatório pós-upgrade (config não é hot-reload) |
| `package-lock.json` dessincronizado (install parcial ou sdk em versão antiga) | Média | Médio | Task 2 verifica plugin E sdk em `1.18.23` no lock antes de prosseguir; se inconsistente, `rm -rf node_modules package-lock.json && npm install` dentro de `.config/opencode/` |
| Fixes de Cloudflare AI Gateway (1.18.23) alteram comportamento de providers usados via gateway | Baixa | Médio | Smoke test de provider pós-upgrade (se o usuário usa Cloudflare AI Gateway); changelog indica fix de routing, não breaking change de config |
